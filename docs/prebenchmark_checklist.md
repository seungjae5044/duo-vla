# Pre-benchmark checklist

This file separates demonstrated engineering facts from conditions that must still pass before reporting policy
benchmarks. A training-loss decrease does not close any rollout or architecture gate.

| Priority | Gate | Current evidence | Closure condition |
| --- | --- | --- | --- |
| Closed | Decoder/cache parity gate | Pinned real BF16 TP=2 SDPA, one 532-valid-token probe, `H=8`: fresh/reused KV and output plus native/adapter all 30 layers were byte-identical; cache pointer/version/hash remained unchanged. Production LIBERO pads the authenticated 529–544 inventory to `P=545`, retaining a one-token sentinel so no replica batch takes SDPA's `mask=None` elision path. The real fixed-B=8 TP=2 qualification passed prefix/output/loss/gradient byte parity in `/root/.cache/duo-vla/fixed-b8-qualification-v1.json` (report SHA-256 `92c8c83de975401b71a2a7496fd74bf00bcb79f94119e0a077217d6eecda7eaa`) | Keep `scripts/check_real_diffusion_gemma_parity.py` and the fixed-B=8 gate in every pinned-runtime qualification before final runs |
| Closed | Independent evaluation randomness | Strict IPC v4 requires a predeclared evaluation seed and hashes only evaluation/reset/replan identity; train seed, objective, NFE, K, and checkpoint are excluded | Keep the same registered evaluation seed and exact 1,999 reset identities across every frozen comparison cell |
| Closed | Test-set isolation implementation | One LIBERO Goal task 7/state 0 cell was already observed; official-score authenticates `evaluation_contamination.json` and its companion SHA, rejects arbitrary subsets, and excludes that identity from every one of the 24 factor cells | Freeze the actual 24-cell pre-registration before the first official policy call; report only the enforced 1,999-episode primary denominator |
| Closed | CALVIN G5 development rollout | The seed-0 update-500 flow pilot completed 2/12 authenticated held-out A/B/C subtasks at `K=4`, `NFE=10`: scene A/B/C successes were 1/4, 0/4, and 1/4; `plumbing_only=false`, `gate_passed=true`, and no learned policy accessed or was scored on D | Keep this development-only result separate from official sequential ABC→D metrics |
| Closed | Checkpoint identity implementation | Official-score requires update 30,000 to be the authenticated run-journal tip and binds its manifest/source/policy/runtime hashes in the selected pre-registration cell | Populate the final hashes after training and freeze the complete 24-cell manifest before scoring |
| Closed | Pinned architecture guards | Hidden size, layer count, canvas length, exact 115-target `q/k/v/o` topology, cache/mask length equality, and the native 1,024-position sliding-window ceiling are fail-closed | Re-run the guards whenever the pinned model/runtime changes |
| Closed | Latency estimand | Rollout mode requires at least one synthetic policy warm-up call (default two), excludes it from episode latency, and records every discarded call in `run.json` | Freeze the warm-up count across comparison cells and report episode-only p50/p95 |
| Medium | Conditioning use | Fixed-noise real flow output changes under language, each camera, state, and camera-swap interventions; repeated baseline and cache-on/off parity are exact | Measure semantic negative-control degradation on hashed clean development rollouts |
| Closed | LIBERO one-task G4 | On four authenticated clean resets, update-500 flow scored 4/4 at K=1 and 1/4 at K=4; direct scored 0/4 at K=1 and 4/4 at K=4 | Keep these as development-only evidence; do not pool K or treat four resets as a benchmark estimate |
| Open | LIBERO sealed benchmark | The clean one-task pilot proves end-to-end control but is too small and uses incomplete development checkpoints | Train the predeclared final checkpoints for three seeds, freeze all hashes/cells, then run the sealed matrix |
| Open | Official CALVIN ABC→D | The archive, A/B/C normalization and split, production G3, completed 500-update checkpoint and reload, and held-out A/B/C development rollout are authenticated; no official D policy score exists | Train the predeclared 30,000-update checkpoints for three seeds, freeze the full 24-cell pre-registration, then execute each indivisible 1,000-sequence D run once |

Suffix gradient checkpointing is not currently enabled. It is an optional memory optimization, not a correctness
requirement; any future enable path needs output/gradient parity before use.
